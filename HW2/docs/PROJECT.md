# 課堂報告：Kaggle Multiple Linear Regression Lab

## 專案動機

同一種回歸方法，在房價、歌曲流行度、電腦規格、租借需求、二手車、租金與機票上是否有相同表現？增加特徵是否一定讓預測更好？本專案用七份獨立資料，在同一個互動介面呈現可重現的實驗，讓比較建立在實際證據上。

## 研究問題

1. 線性模型加入 L1／L2 正則化後，是否改善驗證誤差？
2. Random Forest 捕捉非線性關係後，是否優於線性回歸？
3. 前向特徵選擇的最佳組合是否包含全部欄位？
4. 訓練與驗證的學習曲線差距、殘差規律能否支持模型診斷？

## 實驗設計

各資料集先做來源與欄位核對。排除目標洩漏、識別碼與重複觀測，再將資料分成 80% 訓練、20% 測試。一般資料使用固定種子 42；自行車使用時間順序。補值、標準化、OHE、目標縮放皆在訓練 CV fold 內學習。五模型經 5-fold CV 調參，依 CV RMSE 推薦模型；測試集保留為最後評估。

前向特徵選擇每次加入讓訓練 CV RMSE 最低的欄位；類別欄位以整組 OHE 納入，遍歷至全部候選欄位。最佳特徵數由 CV 選擇，測試曲線只作事後展示。CV 同時用於多次搜尋，因此 CV 成績可能偏樂觀，不能當成獨立泛化證據。

## 技術成果

Python 共用框架產生獨立的模型、完整評估表、診斷、JSON、CSV 與 PNG。React／TypeScript／Vite／Recharts 共用六個頁面元件，只透過 Dataset ID 切換內容。瀏覽器讀取訓練後的前處理參數與線性係數／森林節點，直接計算預測，因此可以在 GitHub Pages 運作。對照案例檢查 JavaScript 和 Python 的結果一致。

## 報告展示順序（約 8–10 分鐘）

1. 用 King County 說明資料來源、80/20、CV 與測試集角色。
2. 展示五模型比較；解釋深綠色推薦由 CV 決定，不由測試 R² 決定。
3. 展示前向選擇曲線，對照最佳特徵數與全特徵分數，回答「特徵越多越好嗎」。
4. 用殘差與學習曲線說明過擬合／欠擬合的證據及診斷限制。
5. 切換 Spotify，展示不同單位與欄位；指出不同資料集的 RMSE 不可直接橫比。
6. 切換 Laptop／Bike／Used Car／House Rent／Flight，確認同一頁六區同步變更、表單不同，並執行一次真實預測。
7. 展示租屋與機票原始特徵不足的標示與工程方案，說明資料驗證比湊欄位重要。
8. 下載 CSV／PNG／報告，展示可重現流程與自動化測試。

## 結論撰寫方式

請以網站當前真實結果與各組 `report.md` 整理結論，勿預設某一模型一定最好。說明哪組資料推薦何模型、CV／測試差距、最佳特徵組合與重要欄位，再指出資料偏差與適用範圍。係數與重要性是預測關聯，不代表因果。原始特徵不足的兩組工程方案必須與教師確認；衍生欄位不等於原始欄位。
