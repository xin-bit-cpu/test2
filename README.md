# 曾郁欣 個人首頁與台灣即時時間動態網站 (NCHU)

本專案為**曾郁欣**的專屬個人首頁，結合**國立中興大學 (NCHU)** 校園特色，並提供高精度**台灣標準時間 (Asia/Taipei, UTC+8)** 動態時鐘與多功能個人工具。

## ✨ 特色亮點

- **個人品牌與學校榮譽**：突顯「曾郁欣」個人名片、國立中興大學校徽意象與「誠、樸、精、勤」校訓。
- **高精度台灣時間動態中心**：
  - 嚴格鎖定 `Asia/Taipei` (UTC+8) 台灣標準時間，毫秒級平滑刷新。
  - 支援「霓虹數位時鐘」與「琉璃模擬指針鐘」雙模式切換。
  - 完整年月日、星期、農曆歲次與節氣。
- **校園風華專區**：介紹中興大學知名地標（中興湖、黑森林、阿勃勒黃金雨大道）與台中南區校園天氣模擬。
- **世界時區即時對照**：即時換算台灣 vs 東京、倫敦、紐約、雪梨時間。
- **實用工具箱**：郁欣專屬學習番茄鐘、每日勵志金句、一鍵複製時間戳記。
- **四款質感主題**：極光夜空 (Default)、興大翡翠綠、夢幻紫霓、明澈白晝。

## 🚀 如何在本機運行

直接用瀏覽器開啟 `index.html` 即可瀏覽。
或使用 Python 快速架設本地伺服器：
```bash
python -m http.server 8080
```
於瀏覽器開啟 `http://localhost:8080`。
