台灣一週天氣預報儀表板 專題介紹

這是什麼
一個看台灣天氣的網頁。資料來自中央氣象署，整理在同一頁，打開就能看到全台 22 個縣市的天氣預報。
網址：https://xin-bit-cpu.github.io/test2/
可以做什麼
• 看全台概況：平均氣溫、哪裡最熱、哪些縣市會下雨
• 看雷達和衛星雲圖動畫：最近 90 分鐘的雲和雨怎麼移動
• 查自己縣市的天氣：可以按地區篩選，或直接搜尋縣市名稱
• 看原始資料：氣象署給的資料長什麼樣子
• 換成即時資料：輸入氣象署的金鑰，就會抓最新預報
怎麼做的
網頁向中央氣象署的開放資料 API 要資料，把拿到的資料整理後顯示在畫面上。沒有金鑰也沒關係，網頁內建一份範例資料，一樣能完整展示。網站放在 GitHub Pages 上，不用另外架伺服器。
